# 记录人类完蛋全过程

一个**无构建步骤**的静态档案馆：记录从 ENIAC（1946）到当下值得记下的 AI 里程碑，并用「人类剩余血条」估算各领域还剩多少人类的事。

打开方式：直接双击 `index.html`，或把本目录部署为 GitHub Pages **仓库根目录**。无需 npm。

> 本分支（`redesign/v2`）是前端重构版：保留全部数据与世界观，重做信息层级与交互。设计以 **16:9 桌面屏（1920×1080 / 1366×768）** 为基准，每个章节一屏；窄屏有降级布局。

## 页面结构

1. **总览**：总血条（50 格，每格 2%）+ 年度里程碑柱状图，直观看到「完蛋在加速」。
2. **领域血条**：左侧 9 个领域，右侧细项详情（按剩余由少到多）；另有「全部排行」视图，支持仅看临界与搜索。
3. **时间线**：左侧大年份随阅读位置变化，可按时代 / 高影响筛选。

**血条 ↔ 时间线互通**：细项里的「推动模型」按名字与时间线事件匹配，点击模型名跳到对应事件；事件卡片展开后可看到它推动了哪些细项，点击跳回领域。匹配规则在 `app.js` 的 `titleMatches`。

## 重要声明

**血条是编辑估算（估算），不是测量。** 基准日写在 `data.json` 的 `updated` 字段。界面会标注「估算」，请勿当作科研结论引用。
时间线条目的日期与模型名均应可核验；不确定的条目不要写进数据。

## 如何改数据

唯一内容源是 **`data.json`**：

- `events`：追加时间线。字段：`date`（ISO）、`title`、`blurb`（中文一句）、`era`、`tags`、`impact`（`high` / `mid` / `low`）。
- `domains`：领域树。父节点可有 `note`；子节点（叶）需有 `remaining`（0–100）、`note`、`movedBy`。
- 父级血条**不要手写**：页面用子节点算术平均并取整。全站总剩余 = 全部叶节点平均。
- `movedBy` 里的模型名若与某个事件 `title` 开头一致（如 `Claude Opus 5`、`GPT-5`），会自动产生跨链接；多个模型用 `/` 分隔。

改完保存即可；刷新页面生效。

本地用浏览器直接打开 `index.html`（`file://`）时，请同步维护 `data.js`（`window.__HUMANITY_DATA__ = …`，内容与 `data.json` 一致）。HTTP 静态托管优先读取 `data.json`。可用：

```bash
python3 -c "import json;from pathlib import Path;d=json.loads(Path('data.json').read_text(encoding='utf-8'));Path('data.js').write_text('window.__HUMANITY_DATA__ = '+json.dumps(d,ensure_ascii=False,indent=2)+';\n',encoding='utf-8')"
```

## 文件

| 文件 | 作用 |
|------|------|
| `index.html` | 结构 |
| `styles.css` | 样式（无外部字体，系统字体栈） |
| `app.js` | 读取数据、渲染血条 / 排行 / 时间线、跨链接 |
| `data.json` | 全部文案与分数（HTTP 源） |
| `data.js` | `file://` 回退包装，与 JSON 同内容 |

## 设计备忘

背景 `#0b0b0a`，骨色字 `#efe9dc`。血条按剩余量分级着色：`>50%` 绿、`26–50%` 琥珀、`≤25%` 临界红；已让渡给 AI 的部分用暗红斜纹表示。标题用衬线，数字用等宽。
