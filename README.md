# 记录人类完蛋全过程

一个**无构建步骤**的静态档案馆：记录从 ENIAC（1946）到当下值得记下的 AI 里程碑，并用「人类剩余血条」估算各领域还剩多少人类的事。

打开方式：直接双击 `index.html`，或把本目录部署为 GitHub Pages **仓库根目录**。无需 npm。

## 重要声明

**血条是估算，不是测量。每天核对一次。** 基准日写在 `data.json` 的 `updated` 字段（当前为 2026-10-07）。总览页会显示 `scoreDisclaimer`。请勿当作科研结论引用。

时间线条目的日期与模型名均应可核验；不确定的条目不要写进数据。

## 如何改数据

唯一内容源是 **`data.json`**：

- `events`：追加时间线。字段：`date`（ISO）、`title`、`blurb`（中文一句）、`era`、`tags`。可选 `impact`（`epochal` / `high` / `mid` / `low`），缺省、空值或不认识的字符串都按 `mid` 画点。标准见下一节。旧数据里的三档仍然有效。
- `domains`：领域树。父节点可有 `note`；子节点（叶）需有 `remaining`（0–100）、`note`、`movedBy`。
- 父级血条**不要手写**：页面用子节点算术平均并取整。
- 全站总剩余 = 全部叶节点平均，再取整。

改完保存即可；刷新页面生效。日后可用脚本每天追加一条 `events`、微调若干 `remaining`。没有专属分镜的新事件会使用统一排版卡，结局画面始终挂在**最后一条**事件上。

### 影响程度

`impact` 比的是「没有它，后面的主线会不会不一样」，不是当时的热度，也不是文案长短。拿不准时往下靠一档。同一条主线上的后续发布，不要因为换了版本号就标成 `high`；改写了做法的论文或数据集，也不要因为没有产品发布就标成 `mid`。

| 键 | 界面 | 什么时候用 |
|----|------|------------|
| `epochal` | 时代级 / EPOCH | 改变整个领域或社会之后的走向：研究议程、产业形态，或公众怎么用，以它为分界。全库只留给极少数拐点。不是「当时最轰动」，也不是「当时最强的模型」。 |
| `high` | 高 / HIGH | 一个阶段或一条主线的关键节点。新范式里被后续工作默认沿用的奠基结果，把能力推进到新场景并被广泛跟随的系统，或清晰拉开一代的旗舰。会改写一个子领域或产品世代，但不会单独改写全领域的走向。 |
| `mid` | 中 / MID | 重要，但仍走在既有主线上：有影响力的方法、数据集、产品、开放权重或机构节点。推动竞争或普及，没有改写这一阶段在问的问题。缺省档。 |
| `low` | 低 / LOW | 代内小幅迭代、速度或成本变体、同系列刷新。值得记入档案，但不改变竞争格局或研究议程。 |

本地用浏览器直接打开 `index.html`（`file://`）时，请同步维护 `data.js`（`window.__HUMANITY_DATA__ = …`，内容与 `data.json` 一致）。GitHub Pages / 任意 HTTP 静态托管优先读取 `data.json`。可用：

```bash
python3 -c "import json;from pathlib import Path;d=json.loads(Path('data.json').read_text(encoding='utf-8'));Path('data.js').write_text('window.__HUMANITY_DATA__ = '+json.dumps(d,ensure_ascii=False,indent=2)+';\n',encoding='utf-8')"
```

## 界面

整站是一块 1920×1080 的 16:9 舞台，按视口等比缩放。四个章节以斜切快门切换，深浅交替：

| 章节 | 内容 |
|------|------|
| 00 总览 | 标题、总剩余、领域血条缩略、最新里程碑 |
| 01 时间轴 | 由浮点位置 `pos` 驱动的图形分镜与让渡曲线 |
| 02 领域血条 | 全部领域；选中后展开叶节点，叶节点可再展开注释 |
| 03 出局名单 | 全部观察项按剩余升序，临界线 25% |

顶栏是全局 HUD：标识、章节、基准日、三套配色。右侧是章节进度，底栏是坐标与操作提示。

配色在右上角切换，或按 `T` 循环，选择写入 `localStorage`（键 `he-theme`）。每套只定义十余个基础色，其余由 `color-mix` 派生：

- `endfield` 终末地黄黑（默认）
- `cobalt` 蓝白
- `tundra` 苔原信号绿

字体：Barlow Condensed（数字与拉丁标题）、Noto Sans SC（中文）、JetBrains Mono（编号与日期）。

### 时间轴

底部迷你轴与主时间轨使用同一套间距：相邻事件至少留出可读空隙，间隔的年数再按对数拉开。因此近年密集发布不会挤成一团，早期长间隔也不会像等距序号轴那样被压扁。年份标在轨上。影响力用刻度高度区分：时代级是更高的强调色菱形，高是实心菱形，中是圆点，低是小方点。轨的右上角有四档图例和计数。不认识的 `impact` 按中档画。

唯一播放状态是浮点 `pos`（事件序号）。拖拽、滚轮、方向键或自动回放都只改目标位置，画面由偏软的弹簧跟上——任意中间位置对应确定的一帧。自动回放从 1946 起连续前进，早期大约每秒三分之一个事件，越靠近现在越快，2020 年代会明显快于四五十年代；经过每个事件时仍略放慢，时代级事件附近会再慢一档，不会停住再跳到下一条。左侧说明随事件擦除换页，影响程度用四格刻度表示（时代级四格全亮）。右侧分镜跟时间轨一起左移，和对应刻度保持相对静止；滑进左侧文字区之前会淡出。停在时代级事件上时，分镜右上角会多一块 EPOCH 标。松手后停在松手的位置；拖拽甩动会再惯性滑一段。上一条 / 下一条、底部刻度、阶段和方向键仍滑到对应事件。指针悬停或拖动、滚轮、按键会暂停；播到最后停住，不跳回开头。系统开启「减少动态效果」时不自动播放，拖动时分镜仍跟着时间轨走。滚轮推到两端再继续，会切到上一章或下一章。

关键事件有平面分镜（真空管、图灵诘问、倒下的王、第 37 手、参数量比例尺、辞职信对话，以及近年的成本与价格对照等）。没有专属分镜的事件用统一排版卡。让渡出去的工作以标签从人一侧滑向机器一侧。

「人类剩余」曲线和右侧斜线填充的机器领地，由叶节点 `movedBy` 与事件标题匹配推算：命中处降到该项当前剩余，未命中的项自 ChatGPT 起线性下降，终点等于总览页的总剩余。曲线只实线画到当前位置。这是示意，不是逐日记录。

### 操作

- 滚轮、↑ ↓ 或页首/页尾键切换章节（领域章里 ↑ ↓ 改为切换领域，PageUp / PageDown 仍换章）
- 顶栏按钮、总览的领域缩略条可直达
- 时间轴：拖动、滚轮、← →、空格
- 触控：纵向轻扫换章；时间轴区域为拖动 scrub
- `T` 切换配色
